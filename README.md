# 🎬 Автоматизация видео для маркетплейсов

Python-скрипты для создания профессиональных видеообложек из фотографий товара за 10 секунд. Без дизайнеров, без водяных знаков, без потери качества и пропорций.

Идеально для **Wildberries**, **Яндекс Маркет** и других маркетплейсов.

---

## 🚀 Запуск за 1 минуту (без установки программ!)

1. Нажмите кнопку ниже — проект откроется в **Google Colab** (бесплатная облачная среда):

   [![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/ksmagronom/marketplace-video-automation/blob/main/main_colab_notebook.ipynb)

2. Загрузите свои фото товара в папку `images` (перетащите файлы в левую панель Colab).
3. Выберите нужный скрипт в ячейках ниже.
4. Нажмите ▶️ **Play** — и через 10 секунд скачайте готовый MP4.

---

## 📂 Что внутри

| # | Скрипт | Что делает | Когда использовать |
|---|--------|------------|---------------------|
| 1 | `01_basic_slideshow.py` | Базовая склейка фото, ровно 3 сек на кадр | Универсальный вариант для любой карточки |
| 2 | `02_smooth_crossfade.py` | Плавные кинематографичные переходы | Премиум-товары, имиджевые карточки |
| 3 | `03_ken_burns_zoom.py` | Эффект медленного зума (Ken Burns) | Акцент на деталях: фурнитура, текстура, швы |
| 4 | `04_format_adapter.py` | Адаптация под 3:4, 1:1, 9:16 без искажений | Подгонка под требования конкретного маркетплейса |
| 5 | `05_video_to_frames.py` | Нарезка готового видео на 5 кадров | Извлечение фото из видео для карточки |

---

## ⚙️ Технические детали

- **Формат вывода:** MP4 (H.264), 24 fps
- **Сохранение качества:** исходные пропорции, цвет и резкость не страдают
- **Цена:** 0 ₽. Без водяных знаков, подписок и ограничений
- **Совместимость:** Google Colab (рекомендуется) или локальный Python 3.8+
